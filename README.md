# Application de Gestion des Ventes - Cesaplast

## Description

Ce projet a été réalisé dans le cadre de mon Projet de Fin d’Année (PFA) au sein de l’entreprise **Cesaplast**.

Il s’agit d’une application de gestion des ventes conçue pour faciliter le suivi des produits, des ventes et des opérations commerciales de l’entreprise. L’objectif principal est de centraliser les informations, réduire les erreurs liées à la gestion manuelle et améliorer l’organisation du travail commercial.

## Contexte du projet

Dans une entreprise, la gestion des ventes et des produits peut devenir difficile lorsqu’elle est réalisée manuellement ou à travers plusieurs fichiers séparés. Cela peut provoquer une perte de temps, des erreurs de saisie et un manque de visibilité sur les opérations commerciales.

Ce projet propose une solution informatique simple et organisée permettant à l’entreprise de mieux gérer ses données commerciales.

## Objectifs

- Gérer les produits de l’entreprise
- Enregistrer les ventes réalisées
- Suivre les opérations commerciales
- Centraliser les informations dans une seule application
- Améliorer l’organisation et la consultation des données
- Réduire les erreurs liées à la gestion manuelle

## Fonctionnalités principales

- Gestion des produits
- Ajout, modification et suppression des données
- Enregistrement des ventes
- Consultation des informations commerciales
- Suivi des opérations de vente
- Interface simple et facile à utiliser
